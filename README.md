# Around The U.S.

## Descripción

Around The U.S. es una aplicación web interactiva que permite editar la información del perfil de usuario, agregar nuevas tarjetas con imágenes, eliminar tarjetas, marcar publicaciones con "like" y visualizar imágenes en ventanas emergentes.

El proyecto fue refactorizado utilizando Programación Orientada a Objetos (POO) y TypeScript para mejorar la organización, reutilización y mantenibilidad del código.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- TypeScript
- Programación Orientada a Objetos (POO)
- Metodología BEM
- Diseño responsivo
- Git
- GitHub

## Funcionalidades

- Edición del perfil de usuario.
- Agregado de nuevas tarjetas.
- Eliminación de tarjetas.
- Sistema de likes.
- Visualización de imágenes en popup.
- Validación de formularios.
- Cierre de ventanas emergentes mediante botón, clic externo o tecla Escape.
