# Around The U.S.

## Descripción

Proyecto web interactivo desarrollado con HTML, CSS y JavaScript.  
Permite editar el perfil de usuario, agregar tarjetas con imágenes y dar “like” a las publicaciones mediante una interfaz dinámica y responsiva.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Metodología BEM
- Git y GitHub
- Diseño responsivo
